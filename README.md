
  # Futuristic Mobile App UI

  This is a code bundle for Futuristic Mobile App UI. The original project is available at https://www.figma.com/design/joq3a1LqmyhrviSUDYhx8d/Futuristic-Mobile-App-UI.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Telegram Mini App setup

  Set `TELEGRAM_BOT_TOKEN` in the Supabase Edge Function environment before deploying. The backend rejects protected requests unless `X-Telegram-Init-Data` verifies against that bot token.
